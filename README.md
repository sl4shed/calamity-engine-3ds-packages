# Calamity Engine 3DS pacman repository

Basically, instead of dealing with the devkitPro people and begging for a pr to be merged (which will probably never happen) i made my own pacman repo.

To use it, add it to your pacman/dkp-pacman configuration file:

```ini

[calamity-3ds-packages]
SigLevel = Optional TrustAll
Server = https://calamity.sl4shed.xyz/3ds/
```
